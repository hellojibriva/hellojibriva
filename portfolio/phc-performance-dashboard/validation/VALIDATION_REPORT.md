## 4. Unresolved issues and limitations

1. **The `.pbix` and the screenshots don't exist yet.** Power BI Desktop was unavailable, so tests B1–B15 are pending.
2. **The DAX was checked statically, not executed.** The lint confirms syntax balance and that every reference resolves. Values were verified with an independent implementation, not with the DAX engine.
3. **Residual re-identification risk at adopter level**, from facility counts and patterns (see DATA_PREPARATION.md §2). Clearance from the data owner is required before public release.
4. **Source limitations carried forward:** September is partial; June is spiked; one adopter has non-response; immunization is counted as doses; cross-sectional ANC ratios; mortality is an upper bound; no population denominators or targets.
