# DAX measure inventory

All measures live on a disconnected `Measures` table, are explicit (no implicit aggregation), use `DIVIDE()` for every ratio and compute ratios as ratio-of-sums. Source: `measures.dax` (84 measures). Generated by `scripts/build_model_assets.py`.

## 0 Base

| Measure | Format | Definition / interpretation |
|---|---|---|
| **Service Value** | `#,##0` | Sum of indicator values in the current filter context. Blank when every value is missing (no report / not captured) – never converted to zero. |
| **Values Recorded** | `#,##0` | Number of facility-month-indicator cells that hold a value (zeros included). |

<details><summary>DAX expressions</summary>

```dax
Service Value =
SUM ( 'FactServiceDelivery'[Value] )
```
```dax
Values Recorded =
COUNT ( 'FactServiceDelivery'[Value] )
```

</details>

## 2 Rates (ratio of sums)

| Measure | Format | Definition / interpretation |
|---|---|---|
| **U5 Malaria Test Positivity %** | `0.0%` | Under-5 positive tests ÷ under-5 tests (ratio of sums). Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **Adult Malaria Test Positivity %** | `0.0%` | Adult positive tests ÷ adult tests. Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **U5 Treated per Positive %** | `0.0%` | Under-5 treated ÷ under-5 positive. A record-keeping ratio, not a clinical treatment rate: values above 100% occur where treatments exceed recorded positives (see data-quality check DQ01). Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **Adult Treated per Positive %** | `0.0%` | Adult treated ÷ adult positive. Can exceed 100% (see DQ02). Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **FP Acceptors per Client Counselled %** | `0.0%` | FP acceptors ÷ clients counselled in the same period (service uptake, not population coverage). Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **ANC4 to ANC1 Ratio %** | `0.0%` | ANC4 visits ÷ ANC1 visits recorded in the SAME period. Cross-sectional continuation proxy, NOT cohort completion: the women counted differ. Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **ANC8 to ANC1 Ratio %** | `0.0%` | ANC8 ÷ ANC1 in the same period (cross-sectional proxy). Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **IPTp3 to IPTp1 Ratio %** | `0.0%` | IPTp dose 3 ÷ dose 1 in the same period (cross-sectional proxy). Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **OPD Share of General Attendance %** | `0.0%` | OPD visits ÷ general attendance. Computed from aggregated numerator and denominator – never an average of facility percentages. |
| **Malaria Test Positivity % (All Ages)** | `0.0%` | All-age positive tests ÷ all-age tests. |

## 3 Reporting

| Measure | Format | Definition / interpretation |
|---|---|---|
| **Expected Reports** | `#,##0` | Facility-months expected to report (60 facilities × months in context). |
| **Reports Received** | `#,##0` | Facility-months with a valid submission (a report with zero values counts as received). |
| **Reports Not Received** | `#,##0` | Expected facility-months without a submission. |
| **Reporting Completeness %** | `0.0%` | Reports received ÷ reports expected. Measures REPORTING, not service coverage or programme effectiveness. |
| **Facilities Expected** | `#,##0` | Distinct facilities expected to report in the period. |
| **Facilities Reporting** | `#,##0` | Distinct facilities with at least one report in the period. |
| **Non-response Months Recorded as 0 in Source** | `#,##0` | Facility-months the source workbook filled with zeros under its non-response rule. Treated as missing in this model. |
| **Missing Report Months** | `#,##0` | Facility-months with no submission that the source left blank. |
| **General Attendance per Report** | `#,##0.0` | General attendance ÷ reports received – a reporting-adjusted volume that removes the effect of missing reports. |

<details><summary>DAX expressions</summary>

```dax
Expected Reports =
SUM ( 'FactFacilityReporting'[Expected] )
```
```dax
Reports Received =
SUM ( 'FactFacilityReporting'[Reported] )
```
```dax
Reports Not Received =
[Expected Reports] - [Reports Received]
```
```dax
Reporting Completeness % =
DIVIDE ( [Reports Received], [Expected Reports] )
```
```dax
Facilities Expected =
CALCULATE ( DISTINCTCOUNT ( 'FactFacilityReporting'[FacilityKey] ), 'FactFacilityReporting'[Expected] = 1 )
```
```dax
Facilities Reporting =
CALCULATE ( DISTINCTCOUNT ( 'FactFacilityReporting'[FacilityKey] ), 'FactFacilityReporting'[Reported] = 1 )
```
```dax
Non-response Months Recorded as 0 in Source =
CALCULATE ( COUNTROWS ( 'FactFacilityReporting' ), 'FactFacilityReporting'[ReportingStatus] = "Not reported (source recorded 0 under non-response rule)" )
```
```dax
Missing Report Months =
CALCULATE ( COUNTROWS ( 'FactFacilityReporting' ), 'FactFacilityReporting'[ReportingStatus] = "Not reported (missing)" )
```
```dax
General Attendance per Report =
DIVIDE ( [General Attendance], [Reports Received] )
```

## 5 Data quality

| Measure | Format | Definition / interpretation |
|---|---|---|
| **Indicator Value Completeness %** | `0.0%` | Share of expected indicator values (fields on the form for facility-months in context) that were actually reported. Excludes not-yet-captured fields. |
| **Fields Blank in Submitted Reports** | `#,##0` | Indicator fields left blank inside a submitted report (source rule recorded 0). |
| **Data Quality Exceptions** | `#,##0` | All flagged checks (DQ01–DQ11) in context. |
| **Logical Inconsistency Flags** | `#,##0` | Checks DQ01–DQ05 and DQ07: a value exceeds the value it should be a subset of. |
| **Facility-Months with Logical Inconsistencies** | `#,##0` | Distinct facility-months with at least one logical-consistency flag. |

<details><summary>DAX expressions</summary>

```dax
Indicator Value Completeness % =
VAR expected = CALCULATE ( COUNTROWS ( 'FactServiceDelivery' ), 'FactServiceDelivery'[ValueStatus] <> "Not captured on form" )
VAR complete = CALCULATE ( COUNTROWS ( 'FactServiceDelivery' ), 'FactServiceDelivery'[ValueStatus] IN { "Reported", "Reported zero", "Corrected upstream (documented)" } )
RETURN DIVIDE ( complete, expected )
```
```dax
Fields Blank in Submitted Reports =
CALCULATE ( COUNTROWS ( 'FactServiceDelivery' ), 'FactServiceDelivery'[ValueStatus] = "Field blank in report (0 per source rule)" )
```
```dax
Data Quality Exceptions =
COUNTROWS ( 'FactDataQuality' )
```
```dax
Logical Inconsistency Flags =
CALCULATE ( COUNTROWS ( 'FactDataQuality' ), 'FactDataQuality'[CheckType] = "Logical consistency" )
```
```dax
Facility-Months with Logical Inconsistencies =
COUNTROWS ( SUMMARIZE ( FILTER ( 'FactDataQuality', 'FactDataQuality'[CheckType] = "Logical consistency" ), 'FactDataQuality'[FacilityKey], 'FactDataQuality'[MonthDate] ) )
```

</details>

## 6 Mortality (national only)

| Measure | Format | Definition / interpretation |
